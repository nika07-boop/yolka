## Важно про «Поделиться с друзьями»

Сам механизм обмена уже реализован. Когда сайт размещён в интернете, кнопка «Поделиться» создаёт ссылку вида:

`https://ваш-сайт/index.html?list=...`

Друг открывает ссылку и сайт автоматически загружает тот же плейлист.

Если открыть `index.html` двойным щелчком с компьютера (`file://`), браузер не может превратить локальный файл в публичную ссылку. В таком режиме кнопка копирует код вечера. Для реального обмена ссылками сайт нужно разместить на любом статическом хостинге.

### Самый быстрый вариант через GitHub Pages

1. Создать аккаунт GitHub.
2. Создать новый публичный репозиторий, например `elka-mediateka`.
3. Загрузить в него `index.html`, `styles.css`, `app.js` и README.
4. Открыть Settings → Pages.
5. В разделе Build and deployment выбрать `Deploy from a branch`.
6. Выбрать ветку `main` и папку `/ (root)`.
7. Сохранить. GitHub Pages выдаст публичный адрес.
8. Открыть этот адрес на телефоне и проверить кнопку «Поделиться».

После размещения ничего менять в JavaScript не нужно: ссылка автоматически строится от текущего адреса сайта.

## Контент

Музыка встроена через Spotify Embed, видео — через YouTube iframe. Книги открываются на страницах Project Gutenberg, где доступны бесплатные электронные версии произведений общественного достояния.

Для конкурсной демонстрации лучше иметь интернет-соединение, потому что внешние плееры и страницы загружаются из интернета.
