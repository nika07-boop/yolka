## Как теперь работает «Запустить вечер»

Кнопка «▶ Запустить вечер» открывает первый пункт плейлиста. В окне появился отдельный блок навигации:

- `← Предыдущий`
- `ПУНКТ 1 ИЗ N`
- `Следующий →`

После нажатия «Следующий» открывается следующий фильм, музыка или книга из «Моего вечера». Можно также нажимать стрелки клавиатуры ← → или прямо нажимать на пункт в списке «Мой вечер».

## Важно про фильмы

Я не добавлял ссылки на пиратские копии/неофициальные сайты вроде Kinogo. Вместо этого в каталоге стоят рабочие ссылки на Кинопоиск и официальные публикации YouTube. У доступности полного фильма и конкретной русской аудиодорожки на легальном сервисе могут быть региональные/подписочные ограничения.

Кинопоиск действительно показывает, например, русские дубляжные дорожки для «Одного дома», «Гарри Поттера» и русские дорожки для советской классики. Официальные полные публикации «Морозко» и «Вечеров на хуторе близ Диканьки» размещены Киностудией Горького.

## Важно про «Поделиться с друзьями»

После размещения сайта в интернете кнопка «Поделиться» создаёт ссылку вида:

`https://ваш-сайт/index.html?list=...`

Друг открывает ссылку — сайт автоматически загружает тот же «Мой вечер».

Если открыть `index.html` двойным щелчком (`file://`), публичную ссылку создать невозможно. В таком режиме копируется код вечера. Для нормальной передачи ссылки сайт нужно разместить на GitHub Pages, Netlify или другом статическом хостинге.

## Самый быстрый вариант публикации — GitHub Pages

1. Создать аккаунт GitHub.
2. Создать публичный репозиторий, например `elka-mediateka`.
3. Загрузить `index.html`, `styles.css`, `app.js` и этот README.
4. Открыть **Settings → Pages**.
5. В **Build and deployment** выбрать **Deploy from a branch**.
6. Выбрать ветку `main` и папку `/ (root)`.
7. Сохранить.
8. Открыть выданный GitHub Pages адрес с телефона.
9. Добавить несколько объектов в «Мой вечер» → нажать «Поделиться» → отправить ссылку другу.

После публикации дополнительной настройки JavaScript не требуется.

## Для конкурсной демонстрации

Лучше заранее собрать в «Мой вечер» 4–6 пунктов: например, Spotify → «Морозко» → книга → «Вечера на хуторе близ Диканьки». Затем нажать «Запустить вечер» и показать комиссии последовательную навигацию кнопкой «Следующий».
