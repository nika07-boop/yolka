# Ёлка-медиатека — мобильная адаптация

Обновлены мобильная вёрстка, сетка каталога, блок рекомендаций и список «Мой вечер». Исправлено переполнение по горизонтали, выровнены надписи конкурсного блока, окно медиа стало удобнее закрывать на телефоне. После нажатия «Зажечь ёлку» или открытия игрушки включается яркое мерцание гирлянд и звезды.

## Как обновить GitHub Pages
1. Распакуйте архив.
2. В репозитории замените `index.html`, `styles.css` и `app.js` файлами из архива.
3. Сделайте Commit changes и подождите минуту-другую.
4. Откройте сайт на телефоне и обновите страницу. Если видна старая версия, сделайте принудительное обновление или откройте сайт в приватной вкладке.
